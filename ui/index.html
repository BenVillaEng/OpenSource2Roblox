λ OpenSource2Roblox Field Manual

1. Quick Start: How to Convert a Map in 3 Steps

  1. Select your Game: In the Maps tab, pick your installed Steam game (e.g. Garry's Mod or CS:GO) from the dropdown or click Browse....
  2. Choose a Map: Click on any map from the list (such as office_summer or gm_construct).
  3. Hit Convert Now: Click the golden CONVERT MAP NOW button at the bottom right. Track the progress in the Console!

2. Understanding Local vs Server-Side Assets

Why did the old version only let you see maps locally?

Standard Source2Roblox copies assets to your personal PC's Roblox Studio folder and writes rbxasset://source/... URIs. This works on your computer, but when published to Roblox or played on a live server, other players do not have those local files, causing grey or invisible textures.

With the Roblox Cloud hotfix, all textures and meshes are automatically uploaded to Roblox's Open Cloud API as permanent rbxassetid:// assets. This makes the map 100% cloud-ready and visible to all players worldwide.

3. Setting Up Your Roblox API Key

  1. Go to the Roblox Creator Dashboard and navigate to Open Cloud > API Keys.
  2. Click Create API Key.
  3. Under Access Permissions, search for Asset System and grant Write (Asset: Create) permission.
  4. Under Creator, select whether you are publishing under your personal User Account or a Roblox Group.
  5. Copy the generated API Key and paste it into the Roblox Cloud tab in this app.
  6. Enter your numeric Creator ID (found in your Roblox Profile URL or Group URL).
  7. Click Test Credentials to verify!

4. Supported Games & Best Practices

  • Counter-Strike: Global Offensive (Build 1.38.8.1): Tested with de_dust2, de_ancient, de_mirage.
  • Garry's Mod (x86-64): Tested with gm_construct, gm_flatgrass, office_summer, toska.
  • Counter-Strike: Source & Half-Life 2: Fully supported.

5. Developer Console Commands

  • status: Displays current conversion engine state and target map.
  • validate: Runs an immediate verification check on your Roblox API credentials.
  • cache: Shows statistics on cached deduplicated textures and meshes.
  • clearcache: Purges the local asset upload cache.
  • steam: Rescans local Steam libraries for Source 1 titles.
  • export: Opens the Windows Explorer export directory.
  • clear: Clears the console log window.
